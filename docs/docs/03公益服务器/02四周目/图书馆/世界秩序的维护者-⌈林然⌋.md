## **世界秩序的维护者-⌈林然⌋**

我们能出现在这个世界，是依托于**世界秩序的维护者——⌈林然⌋**的神力，祂将我们这些被**[⌈尘甲⌋](./伟大的创世神-⌈尘甲⌋.md)**神力影响过的人召唤而来。  
 
 - 祂召唤我们
 - 祂赐予我们创造
 - 祂赐予我们破坏
 - 祂也赐予我们死亡

古老诗歌是这么写的，听说祂召唤来的人出了不少厉害的人，都被一个神秘组织收编了，它们跑到终末之地建造了一堆机器，造建筑用的材料基本都能在那堆机器里找到。  
不过**⌈林然⌋**召唤来的人里头也有不少违反了创世神立下的规则的，被**[⌈尘甲⌋](./伟大的创世神-⌈尘甲⌋.md)**抓到了，听祂吟唱着什么咒语，那些人就被封印了，再也没出现过。  

还有就是，**⌈林然⌋**好像隐匿了法力，转生成小萝莉躲在我们之间了。
